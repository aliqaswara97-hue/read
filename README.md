# أرشيف واتساب (GitHub Codespaces)

## إعداد لمرة واحدة
1. GitHub > Settings > Codespaces > Secrets > New secret
   الاسم: PHONE   القيمة: رقمك بالصيغة الدولية (مثال 9665XXXXXXXX)   واختر هذا المستودع.
2. من المستودع: Code > Codespaces > Create codespace on main.
3. سيعمل التطبيق تلقائياً. إذا ظهر كود في أعلى الصفحة، أدخله في واتساب:
   الأجهزة المرتبطة > ربط جهاز > الربط برقم الهاتف بدلاً من ذلك.

## لاحقاً
عند فتح الـ Codespace يعمل الخادم تلقائياً ويعيد الاتصال بدون كود جديد. السجل في data/server.log
